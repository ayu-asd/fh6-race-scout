# FH6 赛事速览

《极限竞速：地平线 6》线上竞速的选车辅助工具：**粘贴赛事报名界面截图 → 浏览器内 OCR → 直接看三场比赛的赛道线路图**。

游戏里报名时看不到每场比赛的赛道形状，选错车很影响体验；本工具在浏览器本地完成全部识别，不需要把截图发给任何服务器。

## 功能

- **Ctrl+V / 拖拽 / 点击选择**（FilePond 组件）粘贴赛事报名界面全屏截图（支持任意分辨率，按百分比裁剪）
- **Paddle.js OCR**（PP-OCRv3）：推理在浏览器 WebGL 内运行，模型（约 4MB）自托管在本站，首次加载后有缓存
- **三重加权匹配**：OCR 中文名 + 千米数 + 圈数，对照 92 场赛事数据自动纠错（OCR 把 8.2 认成 82、千认成干都不影响）
- 三张卡片展示：中文赛事名 + 赛道线路图 + 可展开的赛事详情图 + 千米/圈数/状态
- **手动查询**：全量 92 场搜索（支持中文/英文/分类），OCR 不准时的兜底
- 识别置信度不足（<55%）时该行降级为**候选列表**（92 场打分排序取前 6）人工点选，其余行不受影响
- 调试模式：可视化裁剪框 + OCR 原文输出（控制台可用 `__fh6DemoLowConfidence()` 随时调出候选界面）

## 使用

1. 在游戏赛事报名界面按 `Win+Shift+S` 截取全屏（或任意截图工具），截图需包含左侧比赛列表
2. 回到本页 `Ctrl+V`
3. 点开"示例截图"按钮可查看什么样截图是有效的

## 识别原理

```
整屏截图
  → 按百分比裁剪比赛列表面板 (x: 13.8%~61.7%, y: 18%~53.5%)
  → Paddle OCR (det 960 + rec) 返回文本框 [文字 + 坐标]
  → 状态机解析（按 y→x 排序，字段只归属同一行内 <90px 的记录）：
      名称 = 纯中文 token（不要求「赛」结尾——北伊根/歌莉娅/
             巨人对决等官方名都不是「赛」尾；以「赛」结尾的 token 优先）
      距离 = /(\d{1,2}(?:\.\d)?)\s*[千干辛][米毛]/（容忍 千→干/辛 误读）
      圈数 = /(\d)\s*圈/
      状态 = 进行中 | 下一步 | 报名中
      噪声 = 含拉丁字母、含「/」「点」的时间天气行、纯数字行号等
  → 加权打分匹配 races.json (92 场)：
      名称相似度(归一化编辑距离)×0.7 + 千米一致×0.2 + 圈数一致×0.1
      ≥55% → 取最高分自动出卡
      <55% → 该行变候选卡，展示打分前 6 名人工点选
  → 垃圾过滤：名称与全部 92 场相似度都 <0.35 且无千米数的 token
      （如"下步"/"享来"）整条丢弃，不占卡片
```

**兜底链**：
- 名称全丢但千米/圈数在 → 各行独立成"无名称记录"，凭千米+圈数给候选（得分上限 0.3 → 必进人工确认，不会误命中）
- 千米文本先于名称出现 → 按 <90px 行内距离自动归并回同一行
- 名称错字（如"弘前攀**仆**赛"）→ 编辑距离 1 → 相似度 0.8×0.7 = 0.56，仍可自动命中

示例（调试模式下的真实 OCR 输出）：

| OCR 原文 | 分类结果 |
| --- | --- |
| `正在加入地平线乐抗亮进费，的1干米` | 标题行 → 丢弃 |
| `伊东径道赛` | 名称 token → 赛事 #1 |
| `进行中` | 状态 |
| `20辛桌`、`o！`、`03` | 噪声 → 丢弃 |
| `夏季/下午4点到6点/雨后多云` | 时间天气行 → 丢弃 |
| `82干米-3圈` | 距离 82(误读, 千米项打 0 分) + 圈数 3 |
| `弘前攀爬赛` | 名称 token → 赛事 #2（名称满分命中） |
| `7.9干米.3圈` | 距离 7.9 + 圈数 3 → 赛事 #3 完美命中 |
| `北伊根`（无「赛」尾） | 名称 token → Kita Ine Street Race |
| `下步`（下一步漏字）、`享来` | 与 92 场全部相似度 <0.35 且无千米 → 整条丢弃 |

匹配容错实例：`弘前攀仆赛` → 与「弘前攀爬赛」编辑距离 1 → 相似度 0.8×0.7 = 0.56 + 千米 8.2 精确 0.2 + 圈数 0.1 = **0.86 ≥ 0.55** 自动命中。

## 开发

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 产物在 dist/
```

数据管线（仅数据更新时需要）：

```bash
node tools/extract.mjs     # 解析 ForzaLabs 保存页 → public/data/races.json
node tools/zhmap.mjs       # 生成中文映射 → public/data/zh_map.json
node tools/fetchmodels.mjs # 下载 OCR 模型 → public/models/
node tools/copyimages.mjs  # 复制 176 张赛道图 → public/images/
```

## 部署

纯静态站，Vercel 直接部署即可；`vercel.json` 已配置模型/图片长缓存。OCR 全部在访客浏览器内完成，无任何服务端计算。

## 数据来源

- 赛事列表与线路图：[ForzaLabs — All Race Tracks](https://forza.labsgg.com/all-race-tracks)（88 场，另手工补录 4 场）
- 游戏内简中名称：游民星空互动地图数据 + 游侠网全赛事位置 + 玩家游戏内截图核实
- 四个"地平线巨献"：歌莉娅（环岛）/ 迎战巨汉（环首都高）/ 苦行赛（泥地拉力）/ 巨人对决（越野）

中文名映射在 `public/data/zh_map.json`，与游戏内不一致可直接修改（`confidence` 字段标注了可信度，`alt` 保留其他来源的译名）。

## 已知限制

- 游戏实际比赛多于数据收录的 92 场（计时赛 ×5、序章等未收录；曾尔环道赛、瀑布径道赛、东京铁道冲刺赛、体育场越野环道赛已手工补录，线路图均来自游戏内截图）；识别到未收录比赛会显示候选列表，可补充 `zh_map.json` + `races.json` 或用手动查询
- OCR 对小字体有少量误读（千→干/辛、8.2→82 等），由容错与打分机制消化
- 需要支持 WebGL 的浏览器；无硬件加速时会走软件渲染（慢但可用）
- 极少数情况下 Windows 的文件选择对话框可能被卡死（点击无反应），`chrome://restart` 重启浏览器即可恢复；Ctrl+V 粘贴与拖拽不受影响
