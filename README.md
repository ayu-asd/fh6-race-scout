# FH6 赛事速览

《极限竞速：地平线 6》线上竞速的选车辅助工具：**粘贴赛事报名界面截图 → 云端识别 → 直接看三场比赛的赛道线路图**。

游戏里报名时看不到每场比赛的赛道形状，选错车很影响体验；本工具自动认出截图里的三场比赛，直接给出对应线路图。

## 功能

- **Ctrl+V / 拖拽 / 点击选择**（FilePond 组件）粘贴赛事报名界面全屏截图（支持任意分辨率，按百分比裁剪左侧列表）
- **云端多模态识别**（Agnes 2.5 Flash）：只上传裁剪后的列表区（约 230KB），识别约 1 秒，不受本机显卡占用影响
- **三重加权匹配**：识别出的中文名 + 千米数 + 圈数，对照 92 场赛事数据自动纠错
- 三张卡片展示：中文赛事名 + 赛道线路图 + 可展开的赛事详情图 + 千米/圈数/状态
- **手动查询**：全量 92 场搜索（支持中文/英文/分类），找不到时的兜底
- 识别置信度不足（<55%）时该行降级为**候选列表**（92 场打分排序取前 6）人工点选，其余行不受影响
- 调试模式：可视化裁剪框 + 识别原文输出

## 使用

1. 在游戏赛事报名界面按 `Win+Shift+S` 截取全屏（或任意截图工具），截图需包含左侧比赛列表
2. 回到本页 `Ctrl+V`
3. 点开“示例截图”按钮可查看什么样截图是有效的

## 识别原理

```
整屏截图
  → 按百分比裁剪比赛列表面板 (x: 13.8%~61.7%, y: 18%~53.5%)
  → base64 上传 /api/ocr（Vercel Serverless Function，密钥只在服务端）
  → Agnes 2.5 Flash 返回结构化文本：名称|千米|圈数（每行一场）
  → 解析每行 → 加权打分匹配 races.json (92 场)：
       名称相似度(归一化编辑距离)×0.7 + 千米一致×0.2 + 圈数一致×0.1
       ≥55% → 取最高分自动出卡
       <55% → 该行变候选卡，展示打分前 6 名人工点选
  → 垃圾过滤：名称与全部 92 场相似度都 <0.35 且无千米数的行整条丢弃
```

匹配容错：名称错一个字（如“弘前攀**仆**赛”）编辑距离 1 → 相似度 0.8，配合千米数仍可自动命中；识别只给到千米/圈数时该行进入候选人工确认，不会误命中。

## 开发

```bash
npm install
echo "AGNES_API_KEY=你的key" > .env   # 本地开发用；生产配 Vercel 环境变量
npm run dev        # http://127.0.0.1:5173（vite 中间件本地模拟 /api/ocr）
npm run build      # 产物在 dist/
```

数据管线（仅数据更新时需要）：

```bash
node tools/extract.mjs     # 解析 ForzaLabs 保存页 → public/data/races.json
node tools/zhmap.mjs       # 生成中文映射 → public/data/zh_map.json
node tools/copyimages.mjs  # 复制赛道图 → public/images/
```

## 部署

Vercel 部署（前端静态 + 一个 Serverless Function）：

1. 导入仓库，Root Directory 选本项目
2. 环境变量里加 `AGNES_API_KEY`（从 Agnes 控制台获取；不要写进前端代码）
3. 部署即可；`/api/ocr` 由 `api/ocr.js` 提供，自动成为 Serverless Function，密钥只在服务端

`vercel.json` 已配置图片/静态资源长缓存。

## 数据来源

- 赛事列表与线路图：[ForzaLabs — All Race Tracks](https://forza.labsgg.com/all-race-tracks)（88 场，另手工补录 4 场）
- 游戏内简中名称：游民星空互动地图数据 + 游侠网全赛事位置 + 玩家游戏内截图核实
- 四个“地平线巨献”：歌莉娅（环岛）/ 迎战巨汉（环首都高）/ 苦行赛（泥地拉力）/ 巨人对决（越野）

中文名映射在 `public/data/zh_map.json`，与游戏内不一致可直接修改（`confidence` 字段标注了可信度，`alt` 保留其他来源的译名）。

## 已知限制

- 游戏实际比赛多于数据收录的 92 场（计时赛 ×5、序章等未收录；曾尔环道赛、瀑布径道赛、东京铁道冲刺赛、体育场越野环道赛已手工补录，线路图均来自游戏内截图）；识别到未收录比赛会显示候选列表，可补充 `zh_map.json` + `races.json` 或用手动查询
- Agnes 免费额度约 20 次/分钟，连续大量识别会触发限流；服务端已做 429 自动重试，仍失败会提示稍后再试
- 截图需包含左侧比赛列表；若裁剪区域偏移（改了游戏 UI 缩放/分辨率），可点“调试”查看裁剪框位置
